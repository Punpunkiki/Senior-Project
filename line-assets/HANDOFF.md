> ⚠️ **อย่าสร้าง Rich Menu ผ่าน Messaging API** เพราะจะไปทับของที่ตั้งไว้ใน
> OA Manager ให้ตั้งผ่านหน้าเว็บ OA Manager เท่านั้น

## 2. Rich Menu

| ไฟล์ | `richmenu-large-2500x1686.jpg` |
|---|---|
| ขนาด | 2500 × 1686 px (ขนาดใหญ่มาตรฐานของ LINE) |
| ขนาดไฟล์ | ~513 KB (เพดานของ LINE คือ 1 MB) |
| เทมเพลต | แถวบนเต็มความกว้าง 1 ช่อง + แถวล่าง 3 ช่อง |
| ตั้งที่ | OA Manager → หน้าแรก → Rich menu → สร้างใหม่ |

### พิกัดและการทำงานของแต่ละปุ่ม

เลือกเทมเพลตที่เป็น **1 ช่องเต็มด้านบน + 3 ช่องด้านล่าง** แล้วตั้งค่าดังนี้

| ช่อง | ตำแหน่ง (x, y, กว้าง, สูง) | ปุ่มบนภาพ | ประเภท | ค่าที่ต้องใส่ |
|---|---|---|---|---|
| A | 0, 0, 2500, 843 | ลิ้งค์ไปเว็บไซต์ | **ลิงก์ (URL)** | URL ของเว็บไซต์ที่ deploy แล้ว |
| B | 0, 843, 833, 843 | วิธีใช้งาน | **ข้อความ** | `วิธีใช้งาน` |
| C | 833, 843, 834, 843 | คลังความรู้ | **ข้อความ** | `คลังความรู้` |
| D | 1667, 843, 833, 843 | วิธีถ่ายรูป | **ข้อความ** | `วิธีถ่ายรูป` |

### 🔴 สำคัญที่สุด: ข้อความต้องตรงทุกตัวอักษร

ช่อง B, C, D ต้องส่ง**ข้อความพอดีเป๊ะ**ตามตารางข้างบน ระบบหลังบ้านจับคำแบบ
ตรงตัว ถ้าพิมพ์เกินหรือขาดแม้แต่เว้นวรรคเดียว กดปุ่มแล้วบอทจะตอบข้อความทั่วไป
แทนที่จะทำงานที่ต้องการ

- ✅ `วิธีใช้งาน`
- ❌ `วิธีใช้งาน ` (มีเว้นวรรคท้าย)
- ❌ `วิธีการใช้งาน`

คำเหล่านี้กำหนดไว้ที่ `app/messages.py` ถ้าจะเปลี่ยนต้องแก้ทั้งสองที่พร้อมกัน

### หมายเหตุเรื่องภาพ

ภาพต้นฉบับที่ได้มาเป็น 2000 × 1349 px ผมขยายเป็น 2500 × 1686 ให้ตรงสเปก LINE
แล้ว ถ้าอยากให้คมที่สุด **export จาก Canva ใหม่ที่ขนาด 2500 × 1686 โดยตรง**
แล้วเอามาแทนไฟล์นี้ได้เลย อัตราส่วนเท่ากัน ไม่ต้องจัดองค์ประกอบใหม่

## 3. ข้อความต้อนรับ (Greeting message)

ตั้งที่ OA Manager → ตั้งค่า → ข้อความต้อนรับ

> สวัสดีครับ ผมหมอทุเรียน 🌿
>
> ส่งรูปใบ กิ่ง ลำต้น หรือผลทุเรียนที่ดูผิดปกติเข้ามาในแชทนี้ได้เลยครับ
> ผมจะช่วยดูให้ว่าน่าจะเป็นอะไร และต้องรีบจัดการหรือแค่เฝ้าระวังต่อ
>
> ถ้ายังไม่แน่ใจว่าเริ่มยังไง กดปุ่ม "วิธีใช้งาน" ด้านล่างได้ครับ
>
> ⚠️ ผลตรวจเป็นการประเมินเบื้องต้นจาก AI ควรปรึกษาเจ้าหน้าที่เกษตร
> ก่อนใช้สารเคมีเสมอครับ

**หมายเหตุ:** ระบบหลังบ้าน**ไม่ตอบ**ตอนมีคนเพิ่มเพื่อน โดยตั้งใจ เพราะปล่อยให้
ข้อความต้อนรับอันนี้ทำหน้าที่แทน ถ้าตั้งให้ระบบตอบด้วยผู้ใช้จะได้รับสองข้อความซ้อนกัน

## 4. ปิดการตอบกลับอัตโนมัติ

ที่ OA Manager → ตั้งค่า → การตอบกลับ

- ✅ เปิด **Webhook**
- ❌ ปิด **ตอบกลับอัตโนมัติ** (auto-reply) ไม่งั้นจะตอบซ้อนกับระบบ
- ❌ ปิด **ข้อความ AI ตอบกลับ** (ถ้ามี)

## 5. ค่าที่ต้องกรอกหลัง deploy

| ค่า | ตั้งที่ไหน | เอาไปใส่ที่ |
|---|---|---|
| Channel secret | LINE Developers → ช่อง Messaging API | `.env` → `LINE_CHANNEL_SECRET` |
| Channel access token | LINE Developers → ช่อง Messaging API | `.env` → `LINE_CHANNEL_ACCESS_TOKEN` |
| Webhook URL | LINE Developers → Messaging API | `https://<โดเมนที่ deploy>/webhook` |
| LIFF ID | LINE Developers → แท็บ LIFF | `.env` → `LIFF_ID` |
| LIFF channel ID | LINE Developers → ช่องที่สร้าง LIFF | `.env` → `LIFF_CHANNEL_ID` |
| URL เว็บไซต์ | — | ปุ่ม A ของ Rich Menu + `.env` → `WEB_BASE_URL` |

**LIFF endpoint URL** ให้ตั้งเป็น `https://<โดเมนที่ deploy>/result`
ระบบจะส่งรหัสผลตรวจต่อท้ายให้เองตอนใช้งานจริง

> ถ้าไม่ตั้ง `LIFF_CHANNEL_ID` หน้าผลตรวจจะ**ตรวจสอบตัวตนไม่ได้** แปลว่าใครก็ตาม
> ที่ได้ลิงก์ไปจะเปิดดูผลตรวจของคนอื่นได้ ระบบจะเตือนตอนเริ่มทำงาน แต่ยังทำงานต่อ
> ดังนั้นต้องตั้งก่อนใช้งานจริง
