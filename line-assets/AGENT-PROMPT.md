# Prompt สำหรับสั่ง Claude ที่ควบคุมเบราว์เซอร์ ให้ตั้งค่า LINE OA

เอกสารนี้มีไว้ก๊อปไปวางให้ Claude ตัวที่เปิดเบราว์เซอร์ได้
(Claude in Chrome หรือ Claude desktop ที่เปิด computer use)

---

## ⚠️ อ่านก่อน: สิ่งที่ agent ทำแทนคุณไม่ได้

ต้องนั่งอยู่ด้วยตลอด และคุณต้องลงมือเองในขั้นตอนเหล่านี้

| ขั้นตอน | ทำไมต้องเป็นคุณ |
|---|---|
| สมัคร LINE Business ID | ต้องยืนยันเบอร์โทรด้วย OTP และยอมรับข้อตกลงในนามตัวเอง |
| สร้างบัญชี OA ครั้งแรก | ผูกกับตัวตนจริง agent ไม่ควรกดยอมรับสัญญาแทนใคร |
| ยืนยันอีเมล / OTP ทุกจุด | รหัสเข้ามือถือหรืออีเมลคุณ |
| CAPTCHA | ตั้งใจออกแบบมาให้คนทำ |

**agent ทำได้** คือหลังจากคุณล็อกอินเข้า OA Manager และ LINE Developers แล้ว
มันช่วยอัปโหลดภาพ ตั้งพิกัดปุ่ม พิมพ์ข้อความ สลับสวิตช์ และตรวจทานว่าตั้งครบ

**เรื่องความลับ:** channel secret กับ access token จะโผล่บนหน้าจอระหว่างทำงาน
agent จะเห็นด้วย ห้ามให้มันพิมพ์ค่าพวกนี้ลงไฟล์หรือส่งไปไหน
ให้คุณคัดลอกไปใส่ `.env` เองกับมือ

## 📋 ก๊อปตั้งแต่บรรทัดนี้ลงไป

```
ช่วยตั้งค่า LINE Official Account ให้หน่อย ผมล็อกอินค้างไว้ให้แล้ว
ผมนั่งอยู่ด้วยตลอด ถ้าเจอ OTP, CAPTCHA, หรือหน้าให้ยอมรับข้อตกลง
ให้หยุดแล้วบอกผม ผมจะกดเอง อย่ากดแทน

บริบท: นี่คือ LINE OA ชื่อ "หมอทุเรียน" เป็นบอทให้เกษตรกรชาวสวนทุเรียน
ถ่ายรูปใบหรือลำต้นที่ผิดปกติส่งเข้ามา แล้วระบบ AI หลังบ้านจะตอบว่าน่าจะเป็นอะไร
งานของคุณคือตั้งค่าหน้าบ้านใน LINE ให้ตรงกับที่ระบบหลังบ้านรออยู่

=== กฎข้อเดียวที่ห้ามพลาด ===

ปุ่มใน Rich Menu สามปุ่มต้องส่ง "ข้อความ" ที่ตรงทุกตัวอักษรตามนี้
ระบบหลังบ้านจับคำแบบตรงตัว ถ้าเกินหรือขาดแม้แต่เว้นวรรคเดียว
บอทจะตอบข้อความทั่วไปแทนที่จะทำงาน และจะไม่มี error ให้เห็นเลย

  วิธีใช้งาน
  คลังความรู้
  วิธีถ่ายรูป

ห้ามเติมอีโมจิ ห้ามเติมเว้นวรรคหน้า-หลัง ห้ามเปลี่ยนคำ
ตอนตั้งเสร็จให้ซูมอ่านยืนยันทีละปุ่มว่าตรงจริง

=== งานที่ 1: รูปโปรไฟล์ ===

ไปที่ OA Manager > ตั้งค่า > ข้อมูลบัญชี
อัปโหลดไฟล์ profile-640x640.png เป็นรูปโปรไฟล์
LINE จะครอปเป็นวงกลม ไฟล์นี้เว้นขอบมาแล้ว ไม่ต้องจัดตำแหน่งเพิ่ม

=== งานที่ 2: Rich Menu ===

ไปที่ OA Manager > หน้าแรก > Rich menu > สร้างใหม่

ชื่อเมนู: เมนูหลักหมอทุเรียน
ช่วงเวลาแสดง: ตั้งให้เริ่มวันนี้ ไม่ต้องกำหนดวันสิ้นสุด
การแสดงผล: ตั้งให้เปิดเมนูอัตโนมัติเมื่อผู้ใช้เข้าแชท
ข้อความบนปุ่มเปิดเมนู: เมนู

เทมเพลต: เลือกแบบใหญ่ (large) ที่แบ่งเป็น 4 ช่อง
          แถวบน 1 ช่องเต็มความกว้าง แถวล่าง 3 ช่องเท่ากัน

อัปโหลดภาพ: richmenu-large-2500x1686.jpg

ตั้ง action ของแต่ละช่อง ไล่จากบนลงล่าง ซ้ายไปขวา

  ช่อง A (แถวบน เต็มความกว้าง)
     ประเภท: ลิงก์ (URL)
     URL: <ใส่ URL เว็บไซต์ของโปรเจกต์>
     ข้อความสำหรับอ่านออกเสียง (ถ้ามีให้กรอก): ลิ้งค์ไปเว็บไซต์

  ช่อง B (ล่างซ้าย)
     ประเภท: ข้อความ
     ข้อความ: วิธีใช้งาน

  ช่อง C (ล่างกลาง)
     ประเภท: ข้อความ
     ข้อความ: คลังความรู้

  ช่อง D (ล่างขวา)
     ประเภท: ข้อความ
     ข้อความ: วิธีถ่ายรูป

กดบันทึกและเปิดใช้งาน

=== งานที่ 3: ข้อความต้อนรับ ===

ไปที่ OA Manager > ตั้งค่า > ข้อความต้อนรับ (greeting message)
ใส่ข้อความนี้ทั้งก้อน รักษาการขึ้นบรรทัดไว้ด้วย

สวัสดีครับ ผมหมอทุเรียน 🌿

ส่งรูปใบ กิ่ง ลำต้น หรือผลทุเรียนที่ดูผิดปกติเข้ามาในแชทนี้ได้เลยครับ
ผมจะช่วยดูให้ว่าน่าจะเป็นอะไร และต้องรีบจัดการหรือแค่เฝ้าระวังต่อ

ถ้ายังไม่แน่ใจว่าเริ่มยังไง กดปุ่ม "วิธีใช้งาน" ด้านล่างได้ครับ

⚠️ ผลตรวจเป็นการประเมินเบื้องต้นจาก AI ควรปรึกษาเจ้าหน้าที่เกษตร
ก่อนใช้สารเคมีเสมอครับ

=== งานที่ 4: ปิดการตอบกลับอัตโนมัติ ===

ไปที่ OA Manager > ตั้งค่า > การตอบกลับ
  เปิด: Webhook
  ปิด: ตอบกลับอัตโนมัติ (auto-reply)
  ปิด: ข้อความทักทายอัตโนมัติอื่น ๆ ที่ซ้ำกับ greeting
  ปิด: AI ตอบกลับอัตโนมัติ ถ้ามีตัวเลือกนี้

ข้อนี้สำคัญ ถ้าไม่ปิด ผู้ใช้จะได้รับข้อความสองชุดซ้อนกันทุกครั้ง

=== งานที่ 5: Webhook (ข้ามได้ถ้าผมยังไม่ให้ URL) ===

ไปที่ LINE Developers Console > ช่อง Messaging API ของบัญชีนี้

  Webhook URL: <ใส่ URL>/webhook
  กดปุ่ม Verify ต้องขึ้น Success
  เปิดสวิตช์ Use webhook

ถ้ากด Verify แล้วไม่ผ่าน ให้บอกผมว่าขึ้น error อะไร อย่าเดาแก้เอง
เพราะอาจเป็นที่เซิร์ฟเวอร์ผมยังไม่ได้เปิด

=== งานที่ 6: LIFF (ข้ามได้ถ้าผมยังไม่ให้ URL) ===

ที่ LINE Developers Console > แท็บ LIFF > Add

  LIFF app name: ผลตรวจหมอทุเรียน
  Size: Full
  Endpoint URL: <ใส่ URL>/result
  Scopes: ติ๊ก profile และ openid ทั้งสองอัน
  Bot link feature: On (Aggressive)

เสร็จแล้วบอกผมด้วยว่า LIFF ID คืออะไร ผมจะเอาไปใส่ไฟล์ตั้งค่าเอง

=== งานที่ 7: Rich message (ทำทีหลังก็ได้) ===

ถ้าผมแนบไฟล์ richmsg-*.jpg มาด้วย ให้สร้าง Rich message สามใบ
ที่ OA Manager > ข้อความ > Rich message โดยยังไม่ต้องส่งออก
แค่สร้างเก็บไว้เป็นฉบับร่าง

  richmsg-welcome-1040x1040.jpg
     ชื่อ: ต้อนรับ-วิธีใช้งาน
     action: ลิงก์ไป <URL เว็บไซต์>

  richmsg-rainy-alert-1040x1040.jpg
     ชื่อ: เตือนหน้าฝน-รากเน่าโคนเน่า
     action: ลิงก์ไป <URL เว็บไซต์>/diseases/canker/

  richmsg-flush-alert-1040x1040.jpg
     ชื่อ: เตือนแตกใบอ่อน-เพลี้ยไฟ
     action: ลิงก์ไป <URL เว็บไซต์>/diseases/thrips/

=== ตรวจทานก่อนจบ ===

ไล่เช็กแล้วรายงานผมเป็นข้อ ๆ ว่าผ่านหรือไม่ผ่าน

  1. รูปโปรไฟล์ขึ้นแล้ว และตัวการ์ตูนไม่โดนวงกลมตัดหัว
  2. Rich Menu เปิดใช้งานอยู่ และภาพไม่เบลอหรือถูกครอปผิด
  3. ปุ่ม B ส่งข้อความ "วิธีใช้งาน" ตรงเป๊ะ ไม่มีเว้นวรรคเกิน
  4. ปุ่ม C ส่งข้อความ "คลังความรู้" ตรงเป๊ะ
  5. ปุ่ม D ส่งข้อความ "วิธีถ่ายรูป" ตรงเป๊ะ
  6. ปุ่ม A เป็นลิงก์ ไม่ใช่ข้อความ
  7. greeting message บันทึกแล้ว
  8. auto-reply ปิดแล้ว
  9. webhook เปิดแล้วและ verify ผ่าน (ถ้าทำขั้นนี้)

ข้อไหนไม่ผ่านให้บอกตรง ๆ ว่าติดอะไร อย่ารายงานว่าเสร็จถ้ายังไม่ได้ทำ
และอย่าพิมพ์ channel secret หรือ access token ออกมาในคำตอบ
```

## หลัง agent ทำเสร็จ คุณต้องทำต่อเอง

1. คัดลอก **Channel secret** กับ **Channel access token** จาก LINE Developers
   ใส่ลงไฟล์ `.env` ด้วยตัวเอง
2. ใส่ **LIFF ID** กับ **LIFF Channel ID** ลง `.env`
3. รัน `python3 scripts/preflight.py --url <URL ของคุณ>` เพื่อยืนยันว่าทุกอย่างต่อกันติด
4. ทดสอบจริงตาม checklist 7 ข้อท้าย `docs/DEPLOY.md`

ถ้าทักไปแล้วบอทตอบข้อความทั่วไปทั้งที่กดปุ่มเมนู
แปลว่าข้อความในปุ่มไม่ตรง ให้กลับไปแก้ที่ Rich Menu
